## Where to start · 어디서 시작할까요

- **I just want to see it:** open the [simulator](../sim/) — it is the landing experience.
  **그냥 보고 싶어요:** [시뮬레이터](../sim/)를 여세요. 첫 화면 경험입니다.
- **I want to build one:** [Build guide](en/01-build-guide.md) →
  [Bill of materials](en/02-bill-of-materials.md) → [Safety & airspace](en/03-safety-and-airspace.md) →
  [Leave no trace](en/04-leave-no-trace.md).
  **직접 만들려고 합니다:** [제작 가이드](en/01-build-guide.md) →
  [부품 목록](en/02-bill-of-materials.md) → [안전과 항공](en/03-safety-and-airspace.md) →
  [흔적을 남기지 않기](en/04-leave-no-trace.md).
- **I want to understand the sync:** [Synchrony explained](en/05-synchrony-explained.md).
  **동기화 원리가 궁금합니다:** [동기화 설명](en/05-synchrony-explained.md).
- **I want to contribute:** [CONTRIBUTING.md](../CONTRIBUTING.md).
  **기여하고 싶습니다:** [CONTRIBUTING.md](../CONTRIBUTING.md).
