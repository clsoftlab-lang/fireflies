## 1. 이것은 무엇이고, 무엇이 아닌가

이 아이디어는 강가에서 시작했습니다. 노을 무렵, 작은 벌레 구름이 공기에 밀려 떠다니고 소용돌이치며,
진짜 반딧불이가 서서히 하나로 맞아 들어가는 리듬으로 깜빡입니다. 반딧불이는 그 느낌을 엄지손톱만 한
빛 수백 개로 다시 만듭니다.

**핵심 설계 선택: 우리는 그들이 어디로 갈지 통제하지 않습니다.** 버튼 하나가 공연을 "시작"합니다 —
개체를 놓아 보내고 불을 켭니다 — 그다음부터는 **바람이 데려갑니다.** GPS도, 위치 유지도, 대형도,
조종도 없습니다. 흩어지는 것은 실패가 아니라, 그것이 *바로 작품입니다.*

이 점이 반딧불이를 상업용 드론 라이트쇼(각 드론을 정밀하게 배치해 글자와 로고를 그리는)와 근본적으로
다르게 만듭니다. 또한 훨씬 단순하고, 훨씬 저렴하고, 진짜 엄지손톱만큼 작을 수 있게 합니다.

| # | 원칙 | 결과 |
|---|---|---|
| F1 | **안무는 바람에게 맡긴다** | GPS 없음, 위치 제어 없음, 충돌 회피 없음. 각 개체는 오직 뜨고 깜빡일 뿐. |
| F2 | **겨우 뜨는 정도의 양력** | 각 반딧불이는 거의 중립 부력으로 다듬은 헬륨 마이크로 풍선이라, 솟구치지 않고 매달려 떠다닌다. |
| F3 | **지휘자 없이 동기화로 깜빡인다** | 각 개체는 자기가 볼 수 있는 이웃 쪽으로 깜빡임을 살짝 당긴다(펄스 결합 진동자, 진짜 반딧불이처럼). 질서는 떠오르고, 아무도 지휘하지 않는다. |
| F4 | **흔적을 남기지 않는다** | 나는 모든 부품은 안전하게 내려와 자연에서 분해되도록 고르고, 회수 계획을 둔다. 이것은 반딧불이이지 쓰레기가 아니다. §7 참고. |
| F5 | **온화하고 합법적** | 낮은 고도, 계류 또는 울타리 옵션, 명확한 항공 규칙, 항공기·사람·야생에 위험 없음. §6 참고. |
| F6 | **누구나 만들 수 있다** | 전 세계에서 구할 수 있는 부품, "기계"는 3D 프린팅 디스펜서 하나, 시뮬레이터는 아무 브라우저에서 실행. |
| F7 | **먼저, 어떤 규모로든 시뮬레이션한다** | 브라우저 시뮬레이터에는 크기나 수의 한계가 없다: 엄지손톱 반딧불이 수천 마리가 떠다니며 동기화되는 꿈을, 링크로 볼 수 있다. 현실은 그 옆에 정직하게 기록한다. |
| F8 | **열린 라이선스** | Apache-2.0 / MIT / BSD / CC-BY 만. |

## 2. 시스템 개요

```
   ┌──────────────── 디스펜서 ("기계") ────────────────┐        바람
   │  헬륨 미세 충전  →  부력 다듬기  →  LED 장착 및 시험  │           ↓
   │  →  한 번에 하나씩 반딧불이 방출     ← 시작 버튼        │   ✦   ✧      ✦
   │  (§4)                                                │      ✧   ✦  ✧     ✦
   └───────────────────────────┬──────────────────────────┘   ✦      ✧      ✦
                               │ 방출                          떠다니며 깜빡임
                               ▼                              느린 동기화로 (§5)
                    ┌──── 반딧불이 개체 (§3) ────┐
                    │ 마이크로 풍선 (He)          │
                    │ + 마이크로 LED + 코인 전지  │
                    │ + 작은 깜빡임 회로          │
                    │ 거의 중립 부력              │
                    └────────────────────────────┘

   브라우저 시뮬레이터 (§8): 반딧불이 수천 마리를 방출하여 바람장 위에서 떠다니게 하고,
   동기화로 깜빡이게 한다 — 하드웨어 불필요, 링크로 공유 가능.
```

두 트랙, 둘 다 오픈소스입니다.
- **시뮬레이터 트랙**(주력): 오늘 당장 전 규모로 꿈이 돌아가는 브라우저 세계.
- **하드웨어 트랙**(기준 설계): 반딧불이 개체와 디스펜서 기계. 물리가 실제 크기와 비행 시간을 제한하는
  지점까지 정직하게 기록.

## 3. 반딧불이 개체 (기준 설계, 하드웨어 트랙)

목표: 실내/아주 약한 바람의 공기에서 떠다니는, 가장 작고 가장 가벼운 자체 발광 부유체.

| 부품 | 선택 | 비고 |
|---|---|---|
| 외피 | 금속 필름("포일 풍선") 마이크로 버블 ~5–8 cm, 또는 생분해 라텍스 마이크로 풍선 | 포일은 헬륨을 더 오래 잡고, 라텍스는 더 잘 분해된다(§7). 엄지손톱 크기(2 cm)는 오늘날 **시뮬레이터 전용** 꿈이다. 전자부품을 조금이라도 들 수 있는 실제 풍선은 더 크다. 정직하게 기록한다. |
| 양력 기체 | 헬륨, **거의 중립 부력**으로 다듬음 | 빠르게 오르지도 가라앉지도 않을 때까지 채운다. 매달려 떠다녀야 한다. 다듬기가 핵심 기술(§4). |
| 빛 | 마이크로 LED 1개, 따뜻한 앰버 기본 + **커패시터로 부스팅한 밝은 번쩍임** | 앰버 ~590 nm는 반딧불이와 맞는다. 번쩍임은 노을에도 보이는 날카롭고 불꽃 같은 "팟"을 준다(§5.1 참고). |
| 전원 | 부력 예산 안에서 뜨는 가장 작은 코인/필름 전지 | 풍선 크기와 깜빡임 듀티에 따라 몇 분에서 두어 시간. |
| 깜빡임 회로 | 작은 마이크로컨트롤러(ATtiny급) 또는 개별 아날로그 블링커 | 펌웨어 옵션은 광센서로 동기화(§5)를 켠다. 아날로그 옵션은 그냥 깜빡인다. |
| 동기화 센서(선택) | 광트랜지스터 1개 | 이웃의 번쩍임을 보고 리듬에 맞춰 들어간다. |
| 질량 예산 | 전부 풍선의 자유 양력 이하 | 탑재물이 가벼울수록 풍선이 작아질 수 있다. 매 밀리그램을 최소화한다. |

### 3.1 두 형태: 반딧불이와 하늘해파리

떠다니고, 바람에 흐르고, 스스로 깜빡이는 같은 개체가 두 가지 시각 형태로 나옵니다.

- **반딧불이 형태:** 깜빡이는 하나의 빛점 — 강 위에 흩뿌려진 불꽃.
- **하늘해파리 형태(해파리):** 헬륨 풍선이 *몸통(bell)*이고, 거기에서 아주 가볍고 빛나는 **촉수**
  여러 가닥이 늘어집니다 — 가는 전도성 실이나 마이크로 필름 리본에 마이크로 LED가 줄지어 달립니다.
  공중에서 촉수는 해류를 탄 해파리처럼 바람을 따라 흔들리고 끌립니다 — 이것이 바로 "바람이 데려가게
  둔다"는 생각(F1)을 눈에 보이게 만든 것입니다. 촉수 설계:
  - **몸통:** 헬륨 마이크로 풍선이 모든 양력을 제공한다. 촉수는 깃털처럼 가볍게 유지해 부력이 거의
    영향받지 않게 한다(촉수의 매 밀리그램이 자유 양력 예산 안에 있어야 한다).
  - **촉수:** 3~8가닥, 각각 마이크로 LED 몇 개. 가닥은 뻣뻣하지 않고 부드럽게 매달려 흔들릴 만큼
    가벼워야 한다.
  - **흐르는 빛:** 빛을 촉수를 따라 **위→아래로** 느린 물결로 흘려서, 해파리가 맥동하며 헤엄치는
    것처럼 보이게 한다(많은 실제 해파리는 이동하는 파동으로 빛난다).
  - **몸통의 불꽃 번쩍임:** 부드럽게 흐르는 촉수 위로, 몸통에서 이따금 커패시터로 부스팅한 번쩍임(§5.1)이
    점화원 없이 선명한 "팟"을 준다.

시뮬레이터는 두 형태를 모두 렌더링합니다. 하늘해파리는 바람장 안에서 흔들리고 빛이 흐르며 끌리는
촉수를 단 몸통으로 그립니다.

**정직한 한계:** 마이크로 LED, 전지, 회로를 싣고도 여전히 뜨는 진짜 2 cm 엄지손톱 개체는 오늘날 기성
부품으로 존재하지 않습니다. 기준 *하드웨어* 개체는 실제로 만들 수 있는 가장 작은 것이고(`hardware/`에
기록), *시뮬레이터*는 2 cm의 꿈을 렌더링합니다.

## 4. 디스펜서 기계

날 풍선 + 헬륨 공급원을 완성된, 빛나는, 중립으로 다듬어진 반딧불이로 바꾸고 버튼으로 방출하는, 3D
프린팅 가능한 데스크톱 기계 하나입니다.

단계:
1. **적재** — 매거진에서 빈 외피를 하나 넣는다.
2. **충전** — 목표 자유 양력까지 헬륨을 채운다. 작은 로드셀/저울로 측정해 부력을 **거의 중립으로
   다듬는다**(F2 뒤에 있는 성패의 단계). 펌웨어가 목표에서 밸브를 닫는다.
3. **장착 및 무장** — LED 탑재물을 붙이고, **점등 자가 시험**(한 번 깜빡)을 돌려 죽은 개체가 방출되지
   않게 한다.
4. **방출** — 운영자의 시작 신호에 따라 한 번에 하나씩, 또는 부드러운 리듬으로 방출한다.
5. **시작 버튼 / 휴대 리모컨** — 유일한 실시간 제어("방출 시작"). 또한 **전체 정지**(방출 중지)이며,
   계류 개체를 내리는 문서화된 계획도 포함한다.

기준 제작: 라즈베리 파이 피코 또는 아두이노급 컨트롤러, 헬륨 라인의 마이크로 서보/솔레노이드 밸브,
부력용 로드셀 + HX711급 증폭기, LED 시험용 포토다이오드, 3D 프린팅 프레임, 매거진, 방출 게이트.
전체 BOM과 배선은 `hardware/`에.

## 5. 동기화된 깜빡임 (이 프로젝트의 심장)

지휘자 없는 진짜 반딧불이도 하나로 맞춰 번쩍입니다. 각 반딧불이는 **펄스 결합 진동자**로 모델링됩니다.
내부 위상이 임계값까지 차오르다가 번쩍이고 리셋됩니다. 이웃이 번쩍이는 것을 *보면* 자기 위상을 조금
앞으로 당깁니다. 무리 전체에서 이것은 동기화로 수렴합니다(Mirollo–Strogatz). 우리는 같은 규칙을
구현합니다.

- 각 개체는 위상을 주기 T(≈ 1–2초) 동안 0→1로 차오르게 하고, 1에서 번쩍이고, 리셋한다.
- 밝은 이웃의 번쩍임을 보면(광트랜지스터) 위상을 작은 결합 ε만큼 앞당긴다.
- 결과: 제멋대로 시작한 반딧불이들이 서서히 함께 깜빡인다 — 바람과 떠다님이 패턴을 결코 똑같지 않게
  만든다. 무선도, 조정자도 없다. 빛이 유일한 채널이다.

**시뮬레이터**는 동일한 모델을 구현하므로, 화면에서 보는 것이 곧 하드웨어가 지향하는 것입니다.

### 5.1 밝기 — 불꽃 없는 불꽃 같은 번쩍임

가만히 켜진 마이크로 LED 하나는 노을에 보기엔 너무 어둡습니다. 그런데 반딧불이 공연이 마법 같은 때가
바로 그 노을입니다. 우리는 전기 불꽃의 날카롭고 밝은 "팟"을 원하지만, **나는 개체에 진짜 불꽃이나
어떤 점화원도 절대 싣지 않습니다.** 자유롭게 떠다니는 물체는 어디든(마른 풀, 사람들, 지붕) 내려앉을
수 있고, 불꽃은 화재 위험입니다. 또한 불꽃은 반딧불이의 부드럽게 반복되는 깜빡임이 아니라 한 번의
"클릭"입니다.

대신 각 반딧불이는 **커패시터로 부스팅한 LED 번쩍임**을 만듭니다. 작은 커패시터가 조용히 충전되었다가
LED로 짧고 강하게 쏟아부어, 카메라 플래시나 자전거 후미등 스트로브처럼 됩니다. 번쩍임 사이에는 어둡고
절정에서 확 밝아져, 선명한 불꽃 같은 "팟"을 주며 노을 진 하늘 멀리서도 보입니다. 앰버에 **차가운
흰색/파란색**을 살짝 섞으면 전기 불꽃의 색까지 흉내 낼 수 있습니다. 불길 없음, 점화 없음, 마이크로
풍선이 들 만큼 가벼움. 절정 밝기, 번쩍임 지속시간, 색은 펌웨어 파라미터입니다. 시뮬레이터는 동일한
날카로운 번쩍임 프로파일을 렌더링합니다.

## 6. 안전과 항공 (실제 비행 전 필독)

- **항공기 안전이 최우선.** 공항 근처나 관제 공역의 자유 부유 발광 물체는 위험하며 대부분의 나라에서
  규제됩니다(한국에서는 항공안전법이 라이트쇼, 풍선 방출, 모든 비행 장치를 규율하며, 허가와 좌표가
  필요합니다). 어디서나 완전히 합법인 기본 모드는 **실내** 또는 **계류**(각 반딧불이를 가는 줄에
  매달아 회수 가능)입니다.
- **자유 방출**(진짜 바람 표류)은 개방되고 낮은 고도의 허가받은 장소에서, 지역 항공 당국과 협의한
  경우에만 — "고급 / 허가 필요"로 기록하며 결코 기본이 아닙니다.
- 군중, 도로, 야생 민감 지역 위로는 검토 없이 비행하지 않습니다.
- 헬륨은 밀폐 공간에서 질식 위험이고 실린더는 고압입니다 — 취급 규칙은 `hardware/`에.
- 배터리: 가장 작은 안전한 전지를 쓰고, 손상된 전지는 절대 방출하지 않습니다.

## 7. 흔적을 남기지 않기 (환경 설계)

- **계류 + 회수** 운용을 우선합니다(아무것도 잃지 않음).
- 자유 방출을 하는 경우: **생분해 외피**, **셀룰로스/종이 LED 캐리어**, 가능한 곳에서는 **회수 가능하거나
  퇴비화되는** 전원을 씁니다. 몇 개를 방출했는지 기록하고 이후 회수를 조직합니다. 방출한 수는 회수/확인한
  수와 같아야 합니다.
- 이 프로젝트는 "수천 개 날리고 그냥 떠나는" 모드를 공개하지 않습니다. 쓰레기는 반딧불이의 반대입니다.

## 8. 브라우저 시뮬레이터 (주력 산출물)

빌드 단계도 외부 서비스도 없는 단일 페이지 웹 앱으로, 전 규모의 꿈을 보여줍니다.
- **바람장**(부드럽고 시간에 따라 변하는)이 반딧불이 수천 마리를 떠다니게 한다. 그들은 퍼지고,
  소용돌이치고, 결코 반복되지 않는다 — 강가의 느낌.
- 각 반딧불이는 **펄스 결합 동기화** 모델(§5)을 돌린다. 관객은 제멋대로인 깜빡임이 느린 하나의
  물결로 모이는 것을 지켜본다.
- 아래쪽 **디스펜서**가 "시작" 버튼에 따라 시간에 걸쳐 반딧불이를 방출한다. 하드웨어 이야기와 맞춘다.
- 컨트롤: 반딧불이 수, 바람 세기, 깜빡임 주기, 결합 세기, 색. 일시정지. "흔적을 남기지 않기" 메모.
  접근성(키보드, 모션 감소, 고대비), 반응형, 라이트/다크.
- 일반 노트북에서 수천 개로 실행되고, 휴대폰에서는 우아하게 성능을 낮춘다.

## 9. 저장소 구조

```
docs/en, docs/ko          설계서, 제작 가이드, 안전, 환경
sim/                      브라우저 시뮬레이터(HTML/CSS/JS, 빌드 없음), 테스트
hardware/                 반딧불이 개체 + 디스펜서: OpenSCAD 부품, BOM, 배선, 펌웨어
firmware/                 깜빡임 + 동기화 펌웨어(개체)와 디스펜서 컨트롤러
site/                     프로젝트 페이지(선택)
```

## 10. 단계

| 단계 | 범위 |
|---|---|
| P0 | 브라우저 시뮬레이터: 수천 개 규모의 바람 표류 + 펄스 결합 동기화 |
| P1 | 벤치 위 반딧불이 개체 하나: 깜빡임 + 빛으로 2~5개 간 동기화 |
| P2 | 디스펜서 기계: 헬륨 충전 + 부력 다듬기 + LED 시험 + 방출, 실내/계류 |
| P3 | 계류 실내 공연(회수 가능), 10~50개 |
| P4 | 자유 방출 — 허가, 생분해 개체, 완전 회수가 있을 때만(고급) |
